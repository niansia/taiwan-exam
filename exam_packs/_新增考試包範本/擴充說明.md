# 新增考試包

新增分科測驗、統測、研究所入學考試或校內考時，複製這個資料夾並完成：

1. 建立 `manifest.json` 與可追溯來源的 `official-baseline.json`。
2. 在 `subjects/科目名稱/` 建立 `subject.json`。
3. 執行 `python scripts/exam_data.py prepare` 產生資料投遞目錄。
4. 使用相同 question schema 匯入逐題 metadata，再建立 learned blueprint。

如果只是新增輸出格式或詳解風格，請新增 renderer 或 answer profile，不要另建考試包。
