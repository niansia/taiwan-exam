# ChatGPT 出卷未套用固定模板

使用者以 ChatGPT 出一份 116 學測數 A，約 13 分鐘完成，但封面、頁首與版型明顯不同，看起來是參考版型後自行重畫。本文記錄檢查結果與修正範圍。

## 檢查結果

| 項目 | ChatGPT 交付的兩份 PDF | Skill 正式流程 |
|---|---|---|
| 產生程式 | XeTeX 輸出、xdvipdfmx 產生 | 內附工具把新正文疊在原始模板上 |
| 原始模板內容 | 兩份各 8 頁，都沒有任何嵌入的頁面物件或圖片 | 封面、頁首頁尾、公式頁為模板原始位元組 |
| 封面 | 以 LaTeX 重排：字型、作答注意事項、劃記範例都不同，頁尾另加「非大學入學考試中心官方試題」 | 固定模板，只填年份、考試名稱與頁碼 |
| 最終檢查 | 沒有執行；這種輸出無法通過固定模板檢查 | `check_hosted_run.py` 通過才可交付 |

13 分鐘之所以快，是因為跳過了套版、逐頁與逐題審閱及最終檢查。規則原本就禁止這種做法：參考文件已寫明不得以其他排版程式重建封面，加註「模擬」也不能讓仿製品合格。本次沒有取得該 ChatGPT 對話的工具紀錄，以下原因依程式與文件推定。

## 原因

1. **原生 Skill ZIP 不含模板。** 前置工具要從 GitHub 下載當科模板，但 ChatGPT 的程式環境通常不能連網；下載失敗時工具會停下，模型卻改走自己的排版路線。
2. **禁止重畫的規則放得太深。** Skill 入口只寫「保留原始固定 PDF 圖層」，沒有直接說不得改用 LaTeX 等工具重畫；完整規則在後段參考文件，模型未讀到或未遵守。
3. **README 的出卷文字寫「請參考排版」。** 容易被理解成照著版型自行繪製。

## 修正

- 原生 Skill ZIP 內建七科正式組版用的 23 份模板 PDF（約 2.3 MB）。打包時逐檔核對大小與 SHA-256；前置工具優先使用內建模板，不連網。內建檔案若損壞會直接停止，不改用下載。
- 載入工具只複製所選科目的模板（非數學 3 份、數學 4 份）。
- Skill 入口、執行指南開頭與前置工具的錯誤訊息都寫明：正式 PDF 只能由內附工具疊在原始模板上產生，並須通過最終檢查；不得以 LaTeX、HTML、Word 或繪圖工具重畫封面、頁首頁尾、劃記範例或公式頁。取不到模板時要停下，請使用者附上離線模板資源 PDF。交付時要回報最終檢查結果。
- README 的出卷文字改為明確要求套用原始模板，並回報最終檢查結果。另新增「封面跟版型不一樣」的判斷方法與重做文字；用專案或 Gem 的人出卷時一併附上離線模板資源 PDF。

## 測試

- 打包：ZIP 內的 PDF 只有這 23 份模板，逐檔與模板對照表一致。
- 七科各自從 ZIP 載入：只複製當科模板；前置工具在網路不可用時仍完成準備，來源標示為內建模板。
- 內建模板被改動一個位元組時，前置工具停止，錯誤訊息要求停下並索取離線模板資源 PDF，不會下載或改用其他排版。

## 限制

Skill 無法強迫模型呼叫工具。這次修正移除「取不到模板」這個最常見的藉口，並把禁止事項放在模型最先讀到的位置。使用者仍可用封面對照與最終檢查結果，自行判斷是否為正式套版的成品。本修正尚未以新的 ChatGPT 實際出卷驗證。
