# 2026-09-12 本機整備紀錄

本次依 `niansia/taiwan-exam` 的 `d9d2bec` 版本進行本機修正。
這是軟體與來源資料的整備紀錄，尚不是七科正式考卷驗收或公開發布證明。

## 已修正

- 來源安裝先檢查路徑與既有檔案，遇到不同內容保留使用者原檔並回報。
  驗證模式也檢查路徑；拒絕重複檔名、大小寫碰撞、符號連結與錯誤內容。
  使用獨立暫存檔與不可覆寫的原子安裝；下載、解壓失敗會清除本次暫存。
- 重新核對六份 115 原卷的題數、計分單位、題型、選項數、配分、作答限制與
  條件計分。保留數 A 原有核對資料。結構審查必須涵蓋每份來源的所有頁面，
  不再接受只核對部分頁面或重複頁面湊數。英文的制度標示與版型同步為 115 起。
- 完整規劃直接使用核對後的計分單位順序；不再從題型總數推測排列。
  保留翻譯、作文及分項計分；原題號與計分單位數分開呈現。
  非選擇題不再誤套用同位置選擇題的實測難度。
- 科目接受國綜、國寫、數 A／B 的無空格簡稱 `數A`、`數B`。
  選擇完整國文卷時要求明確指定國綜或國寫，避免誤選另一份。
- 狀態頁讀取公開發行版的 writer blueprint，私有逐題資料未安裝不再誤報為
  完全沒有校準。新增七份試卷的就緒檢查；缺少題型對應時規劃回傳非零狀態，
  並保留可診斷的完整題位清單，不把缺項計畫宣稱為歷史校準完成。
- 英文舊標註中的文意選填 `fill_in`、作文 `guided_writing` 僅在相同科目與
  大題內作語意等價正規化，保留原標註欄位，不跨大題借用校準。
- 成品檢查核對實際題號、小題識別與母題配分，拒絕重複題目識別碼。
  資料重建保留已核對且未變動的原卷資料；缺少私有 PDF 不會抹掉既有審查。
- 排版與資料格式支援英文翻譯、作文的無連續題號任務，保留大題內的印刷
  標籤與具名詳解，避免 null 題號衝突、排序錯誤或印出空題號。
- 同步官方來源索引、網頁知識檔與下載頁版本；加入投影檔過期檢查。
  新增 Windows／Linux、Python 3.10／3.12 的 CI 設定，保留獨立的發布安全檢查。

## 目前七份試卷的前置狀態

新增 39 筆實際原卷語意標註（113～115 年），補齊先前 53 個計分單位的缺項。
五科新增筆數：國綜 9、英文 12、數 B 3、自然 6、社會 9。每個新增大題／
作答型態至少涵蓋三個官方年度，保留來源 PDF、答案或評分原則的 SHA-256
與實際檢視頁碼。必要圖像已目視核對。難度向量明確標為模型估計，沒有
虛構官方 P/D、獨立人工複核或每個課綱單元均有新增樣本。

新增資料以獨立 ledger 保存，原有 writer blueprint 未被覆寫。三個入口
（完整規劃、前置檢查、成品驗收）共用合併載入器；來源變動、基礎版本
變動、補充檔缺失或彙整不一致均會拒絕。網頁知識檔只帶彙整，不帶逐題
語意 ledger。所有科目仍須完成新題命製、獨立解題、來源查核與題目／詳解
兩份 PDF 的逐頁檢查。

結構核對依每份 profile 綁定的原始試題、答案及評分原則，頁碼為實際 PDF
頁碼（含封面）。社會條件計分與自然圖表、繪圖及分格作答保留在題位紀錄。
本次沒有修改歷屆試題與模考原檔，也沒有用歷屆題改寫成新考卷。

## 驗證方式與限制

```text
python -m pip install -r requirements-test.txt
python -m pytest -q
python scripts/validate_attribution.py .
python scripts/bootstrap_exam_sources.py --all --verify-only
python scripts/audit_exam_pack.py --output output/claims.json
python scripts/audit_exam_pack.py --readiness --output output/readiness.json
```

來源檔檢查：9 個來源包、1,124 個檔案全部通過大小與 SHA-256 核對。
Windows / Python 3.10.10 的乾淨公開副本完整測試：399 通過、2 跳過。
跳過項目需要未隨公開原始碼提供的舊輸出測試資料。另完成七份完整規劃，
皆回傳 0 並保留所有官方計分單位；這些規劃不是新題成品。
候選 v0.7.1 的 308 個檔案通過清單、雜湊、Defender 壓縮檔與解壓後掃描，
以及 Windows 附件儲存檢查；不代表瀏覽器接受或廠商已確認誤判。
結構與版型：14 個已驗證宣告通過一致性檢查。此結果不等於成品內容驗收。
就緒檢查已回傳 0，七份試卷均為 prerequisites-ready；沒有遺漏題型。
公開原始碼不包含私有原卷，CI 會測試其缺檔行為，不能宣稱 CI 已閱讀原卷。

軟體 ZIP 的公開發布仍依 `SOFTWARE_RELEASE_STATUS.json` 暫停，等待一般
瀏覽器下載的確認。9 月 12 日的自動化 Chrome 對純文件來源 ZIP 也顯示
ERR_BLOCKED_BY_CLIENT，不能因此判定新候選有惡意程式。工具安全政策
不允許開啟下載紀錄頁；未變更瀏覽器或系統防護設定。詳細證據見
[候選修正紀錄](../references/security-resolution-2026-09-12.md)。

GitHub 的修正分支、私有候選草稿與遠端 CI 用於完成發布前驗證；公開主分支
與正式下載需依最後驗證結果更新。本次尚未產出最初要求的七份新試卷及七份詳解。
