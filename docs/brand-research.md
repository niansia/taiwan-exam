# 考試與備考品牌的主視覺研究

研究日期：2026-09-24。下列觀察依官方網站實際顯示的主標誌整理，
「設計啟發」是本專案的分析，不代表該品牌對其設計意圖的聲明。

| 官方來源 | 視覺觀察 | 對 Taiwan Exam 的設計啟發 |
| --- | --- | --- |
| [Magoosh GRE](https://gre.magoosh.com/) | 可讀的字標，將相鄰圓形字母融入勾選符號 | 考試的聯想可融入字母的一處，不需要畫完整考卷 |
| [Exam.net](https://exam.net/) | 圈圈與勾號圖標，搭配簡潔小寫字標 | 採一個清楚的作答符號即可建立用途聯想 |
| [Save My Exams](https://www.savemyexams.com/) | 小型閃電圖標與緊湊、易讀的名稱並列 | 主標誌不承擔所有產品說明，先確保縮小後仍清楚 |
| [Knowt](https://knowt.com/) | 有眼睛的簡單方形角色圖標，與正常比例的字標分工 | 角色感可以很小；可愛不必等於複雜的全身插畫 |
| [阿摩線上測驗](https://yamol.tw/) | 導覽列使用小型圓形徽記，首頁以中文考試文字說明用途 | 台灣備考情境可以由繁體中文與在地考試名稱直接表達 |
| [スタディサプリ品牌網站](https://brand.studysapuri.jp/) | 以緊湊、帶稜角節奏的日文字標維持辨識 | 借鏡字形節奏與光學間距，不使用假日文或套用他牌字形 |

## 本專案的方向約束

- 保留英文專案名稱 Taiwan Exam，並以繁體中文「大型考試自動化命題」說明產品定位。
- 讓考試聯想來自勾選、作答圈或字母細節，而不是無關的台灣動物或地圖。
- 建立獨立配色，不沿用 PSG 的粉藍、薄荷、奶油黃、橘四色組合。
- 可愛與二次元感須服從品牌可讀性；避免過大的眼睛、厚重氣泡字與過多裝飾。
- 正式檔案維持原生向量；同時檢查淺色、深色和縮圖。
- 研究用標誌不併入成品，不複製其他品牌的字形、角色或圖標。
