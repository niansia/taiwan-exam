# 分科測驗

**待製作，目前仍在規劃中。**

分科測驗會有獨立的科目規則、版型、安裝方式與實測紀錄。完成製作與驗證後，會在這一頁提供使用入口。

| 項目 | 目前狀態 |
| :-- | :-- |
| 科目與製作順序 | 待整理 |
| 命題規則與參考資料 | 待製作 |
| 專用版型、工具與操作說明 | 待製作 |
| 完整考卷實測紀錄 | 待建立 |
| 開放時間 | 尚未確定 |

目前可用的是**學測七科**，請從 [學測安裝說明](../../README.md#第-1-步安裝)開始。現有學測套件的可用狀態不代表此考試已可用。
