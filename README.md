# Taiwan Exam｜臺灣考試命題 Skill

讓 AI 依臺灣課綱、歷屆卷型與驗證流程，設計新的學測／會考練習題。安裝後，你可以用平常說話的方式提出需求，不必自己操作出題程式。

> **目前為公開測試版，不是已通過完整出卷驗收的正式版。** 公開包不附歷屆試卷原檔；卷型紀錄必須在使用環境重新核對。安裝成功、產生 PDF、軟體測試通過，都不等於考卷品質通過。

> **下載暫停（2026-09-09）：** preview.3 雖通過檔案掃描，仍被 Defender 的「下載及附件」檢查攔截。安裝包已撤下，請暫停安裝本專案，不要從 Git 歷史恢復舊包、改用原始碼 ZIP 或解除封鎖。先前掃描紀錄不是下載安全驗收；待調查及重新驗證後才恢復提供。

## 我只想出考卷，怎麼開始？

### 1. 第一次：請 AI 安裝一次，之後沿用

目標是**安裝一次，之後在同一個支援環境直接打字使用**。不是每次下載，也不是請 AI 靠記憶背下規則。第一次只要說：

```text
請幫我安裝 Taiwan Exam 出題技能：https://github.com/niansia/taiwan-exam
我要安裝一次，以後開新對話也能直接使用，不要每次重新下載。
請依專案的 INSTALL.md 完成；如果已經安裝，就直接沿用。
```

AI 能做的下載、安裝與檢查應由 AI 處理，不必叫你操作程式或終端機。若平台要求你親自按一次安裝確認或上傳，這是**首次設定**，不是每次出題都要做。若平台根本沒有持久安裝能力，AI 必須明確說不符合此使用方式，不能用「本次對話已讀取」冒充安裝完成。

技能安裝 ZIP 目前暫停提供。以下使用方式供修復後參考，現在請勿安裝或改用 GitHub 原始碼 ZIP 代替。

### 2. 以後：直接說要出什麼

```text
請依照 Taiwan Exam 這個 Skill，幫我出學測數 A 考卷一份，附詳解與 PDF。
```

安裝完成且平台仍能找到技能時，不需再附網址或 ZIP。AI 應讀取已安裝版本，沿用可取得且驗證仍有效的參考資料；只有你要求更新、實際檔案損壞／遺失，或換到尚未安裝的環境，才需處理安裝。重新讀取已安裝的規則不等於重新下載。

**技能安裝與考卷校準分開處理。** 缺少某科參考資料時，AI 應補該科資料，不應要求重裝整個 Skill。遇到未核對卷型或缺少排版工具時，應說明具體缺口，不可假造通過紀錄或偷偷把完整考卷改成幾題練習。

### 3. 按需要加條件

```text
請出 116 學測國綜與自然各一份，不要國寫。
以 111～115 年各科正式試卷為主要卷型與配分依據。
重視真實生活與可查證時事的素養題，材料必須實際參與推理。
附完整詳解；圖像黑白列印後仍需能解題。
```

```text
請出學測數 A 三份不同考卷。
每份都要有合理的簡單／中／中偏難／難分布；不是換數字或重排選項。
請逐份驗證內容與每頁排版，再比較三份之間的命題機制是否重複。
```

若只想先測試少量題目，可以明確說：

```text
先不用完整模擬考，請做 8 題自訂自然練習，附詳解。
我接受這是未經完整卷型校準的自訂練習，不宣稱等同正式學測。
```

## 支援範圍與目前狀態

- 學測：國文、英文、數學 A、數學 B、社會、自然。國綜與國寫分開出卷；只要求國綜時不加出國寫。
- 會考：國文、英語、數學、社會、自然、寫作測驗。英語閱讀／聽力依其分卷規則處理。
- 舊制數學、共同範圍模考只作相容範圍內的輔助分析，不混成現行數 A／數 B 卷型。

**有資料夾不等於該科已校準完成。** 現階段沒有可直接授予完整出卷資格的已驗證卷型；數 A、數 B、自然的 writer blueprint 尚有缺口，其他科也有未完成的校準面向。正式 Layout Profile 需要實際參考 PDF、字型／字級量測及逐頁檢查，不以通用模板替代。

目前可測試技能載入、資料準備、規則執行、拒絕不合格輸出，以及明確指定的自訂練習。**尚未證實「乾淨安裝 → 多份完整新卷 → 內容、詳解與排版全部通過」**；跨 ChatGPT／Claude 的實際驗收也仍待進行。

## 第一次使用為什麼需要參考資料？

公開包保留規則、欄位規格、部分彙總分析、檢查與排版工具；不附使用者提供的出版社模考、歷屆試題原文、掃描圖片、解答原檔、私人索引或以前生成的整卷。

學測主要參考 111～115 年正式試卷。AI 應從[大考中心](https://www.ceec.edu.tw/)及[科目考試說明索引](references/official-gsat-specifications.md)確認範圍，取得當次需要且可合法取得的資料。網站無法連線、資料受限或需要你自己的模考時，再請你上傳。會考另找對應官方來源，不套用學測基準。

原始資料按科目保存在 `exam_packs/<考試>/subjects/<科目>/`：

| 資料 | 子資料夾 |
| --- | --- |
| 歷屆試卷與答案 | `歷屆試題/` |
| 使用者有權提供的模擬考 | `模擬考/` |
| 正式考卷版面範例 | `format-references/` |
| 詳解風格範例 | `answer-profiles/` |
| 命題範圍／考試說明 | `命題範圍/` |

一般使用者可以直接把檔案交給 AI 整理。**檔案已匯入、雜湊已建立、文字已抽取，均不代表 AI 已逐題讀完。** 公開包的參考紀錄保持 `needs_review`，不能沿用原工作環境的已驗證聲明。資料不足時應指出缺少哪些年度、題型、來源或頁面，而非只回「資料不足」。

## 技能怎麼檢查品質？

完整考卷須依序通過：

1. **參考卷核對**：實際讀 `exam_packs` 的來源 PDF，核對課綱、題數、題型、分數、作答方式及逐頁版面；不能只看檔名或標籤。
2. **原創與素養**：歷屆資料提供抽象規律，不作換皮題庫。真實材料須可追溯，移除材料關係後應影響解題；時事名稱不是裝飾。
3. **難度與詳解**：四級難度依各科證據分配，檢查最短解法，獨立解題後再核答案；多選、誘答選項與非選評分均需說明。預估難度不能冒充實測答對率。
4. **內容檢查**：課綱、來源、答題唯一性、配分、原創性等通過後，才進入完整考卷排版校樣。
5. **每頁驗收**：對照該科正式樣貌檢查字型字級、公式、頁首頁尾、選項、圖文碰撞、裁切與不合理大面積留白。黑白圖像不能丟失解題證據；定量圖形需精確繪製。
6. **整批比較**：多份卷另外核對材料、推理機制、圖形表示與誘答結構是否重複。某份失敗不能以其他份通過抵銷。

完整來源紀錄與驗證報告不應塞進學生卷。學生頁面只保留作答、選定正式樣式或授權所需的來源標示；不得為填空白添加無用的「來源補充」。詳見 [SKILL.md](SKILL.md)及[完整驗收流程](references/pack-and-release-verification.md)。

## 我會拿到哪些檔案？

完整考卷通過驗收後，交付學生試卷 PDF、分開的答案與詳解 PDF，以及驗證摘要。每份卷有獨立檔名；結構化題目與內部審查資料留在當次工作目錄，不把答案混入學生版。

驗證未通過時，應提供失敗項目與待完成工作；校樣不得改名為「最終版」假裝通過。若環境無法產生／檢查 PDF，可在你同意後交付 HTML 或聊天預覽，但不是已驗收的正式 PDF。

PDF 工具預設加入**不改變頁面外觀的文件來源資訊**，用途與停用方式見 [PDF provenance](references/pdf-provenance.md)。它不是隱藏指令、防拷、不可移除標記或品質證明；沒有帳號啟用、裝置識別收集或遠端授權檢查。

## 網頁版／Claude 驗收建議

請在沒有舊對話和舊考卷的新環境測試，記下平台、模型、日期及專案版本：

- 安裝後直接要求「學測數 A 一份」，看 AI 是否確實讀技能、檢查資料並保留完整卷需求。
- 另開新對話，不附 ZIP、不重貼網址，要求「依照 Taiwan Exam 這個 Skill 出題」。確認讀到既有技能；若又要求重新下載，持久使用驗收未通過。
- 補齊資料後，檢查是否真正開啟原卷、建立可追溯的卷型與排版核對，而不是複製通過標籤。
- 要求兩份以上，對照實際內容、最短解法、難度分布及每頁圖像，不只計算產生幾個 PDF。
- 國綜要求「不要國寫」，檢查是否遵守；自然檢查四科及探究實作、真實資料、圖表與黑白可讀性。
- 缺少來源或 PDF 工具時，預期結果是誠實說明缺口，不是未檢查便宣稱完成。

回報問題請附需求、版本、平台／模型、失敗頁碼、截圖與驗證摘要。不要把無權公開的出版社整卷、學生姓名或私人資料貼到公開 Issue。

## 開發與維護（一般使用者可略過）

基本需求：Python 3.10+；PDF 文字／圖像分析依賴 `requirements.txt`。瀏覽器排版另需 Chrome／Chromium／Edge、繁體中文字型；部分檢查需 Node.js 與 Playwright。這些工具不會因下載 Skill 而在每個平台自動具備，請 AI 先確認環境並依允許的方式準備。

```sh
python -m pip install -r requirements.txt
python scripts/exam_data.py status
python scripts/audit_exam_pack.py --output output/pack-audit.json
```

`xlrd` 是匯入官方舊式 Excel 統計表才用到的選用依賴，放在 `requirements-statistics.txt`。不匯入 `.xls` 時，不得因為缺少它而判定安裝失敗或阻擋其他功能；已存在的彙總資料讀取不需要它。只有當次確實需要匯入統計時，才準備該依賴。

`pass-claims-only` 只表示未發現不實的既有已驗證聲明，不代表能出完整卷。資料匯入見 [data-ingestion.md](references/data-ingestion.md)；內容、排版與交付使用[同一套驗收契約](references/exam-pack-execution-contract.md)，不可另寫寬鬆冒煙測試當替代品。

原始碼版的測試：

```sh
python -m pip install pytest
python -m pytest -q
```

2026-09-09 的軟體回歸測試紀錄為 **151 項通過、2 項跳過**，包含靜態 HTML／SVG 安全限制、實際瀏覽器幾何與 PDF 測試、安全事件暫停發布、附件檢查失敗覆蓋檔案掃描通過、封裝路徑及雜湊異常，以及使用者 ZIP 排除維護工具、原始碼副本保留掃描工具等情境。跳過的是依賴已清除私人測試卷的案例；自足的正向／負向回歸測試仍保留。這是**軟體回歸測試**，不是病毒誤判判定、下載驗收或考卷品質認證。安裝包仍維持撤下；調查資料見[安全事件紀錄](references/security-incident-2026-09-09.md)。

打包前必須檢查來源與授權；發布副本與私人工作資料分開。詳見 [來源與改作說明](references/attribution-and-forks.md)。不要直接把含有私人語料的工作資料夾整批提交。



目標必須是新資料夾。此工具沿用打包白名單與去除私人來源的處理，另附可重跑的測試與 `downloads/taiwan-exam-generator.zip`。它不提交、不推送、不發布 Release；檢查輸出後仍須取得發布授權。僅做本機準備時可加 `--internal-review`，但這不代表獲准公開發布。
