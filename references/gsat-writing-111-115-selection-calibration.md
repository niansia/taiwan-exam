# GSAT writing aggregate calibration, 111–115

This file is analysis-only and must not be opened during a writing pass. It deliberately contains no historical topic, title, proper noun, source identity, image description, or signature metaphor.

## Aggregate observations

- All five verified papers use two major tasks totaling 50 points in 90 minutes.
- The first task consistently uses an 80-character, 4-point reading/integration response followed by a 400-character, 21-point response.
- The first-task question page contains 829–1,141 compact text-layer characters including recurring directions.
- Text-only second-task pages contain 386–617 compact text-layer characters including prompts. A multimodal paper may use another page only when indispensable visual material earns it.
- The two tasks have different rhetorical jobs: evidence integration and bounded judgement versus concrete perception, experience or realized imagination.
- A source must remain necessary after the prompt is written; removing it must change the response decision.

## Firewall

Only these aggregate constraints may be copied into generation instructions. Topic or source inspection is confined to analysis and post-generation veto review. A replacement draft must return to a new autonomous web search, not to a different historical question.
